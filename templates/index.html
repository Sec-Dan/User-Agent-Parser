What is a user agent?

A user agent is the text your browser sends with every web request to identify itself. Sites use it to serve compatible pages and to count visitors, and security teams use it when hunting through logs for unusual clients.

How to read one

Take Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/130.0.0.0 Safari/537.36:

  • Mozilla/5.0 is a historical token nearly every browser still sends for compatibility. It does not mean Firefox.
  • (Windows NT 10.0; Win64; x64) is the platform.
  • AppleWebKit/537.36 (KHTML, like Gecko) is the rendering engine family, also largely kept for compatibility.
  • Chrome/130.0.0.0 is the browser and version. The trailing zeros are deliberate, as Chrome reduces the detail it shares.
  • Safari/537.36 is another compatibility token, and is why Chrome appears to claim it is Safari.

Can you trust a user agent?

Not on its own. The value is set by the client, so anyone can change it, and malware and scrapers often imitate common browsers. Treat it as a useful clue alongside other evidence such as the IP address, which you can look up in OSINT Explorer.
